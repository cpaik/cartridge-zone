Make a cart

Write a character, give it meters and win or lose conditions. The model plays the character and nudges the meters with tags each turn; the page clamps every change, so the numbers stay fair.

Share it

A cart is just this JSON. Copy it to share; paste someone else's to import.

To run the real version: save the file, run python3 -m http.server 8000 in its folder, then open localhost:8000/cartridge-zone.html in Chrome, Edge, or Safari 26+.
Prototype. Models run through WebLLM on WebGPU; weights come from Hugging Face and are cached by your browser. Ratings and plays are stored only in this browser.
